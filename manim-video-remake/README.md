Manim 视频复刻还原 Skill
这是一个经过真实项目反复打磨的 AI 视频逆向复刻技能：只要提供一段目标视频，它就会从成片出发，逐帧提取视觉证据，分析布局、配色、数值、动画节奏和转场形态，再反推背后的 Manim 场景结构与代码实现。
它不要求目标视频一定由 Manim 制作。即使原片来自其他动画或剪辑工具，也可以把画面拆解为 Manim 能表达的对象、公式、图形和动画，尽量复刻出接近原片的视觉效果。复杂作品的最终还原度取决于素材、字体、特效和可观察信息，但这套方法可以把“凭感觉模仿”变成一套可重复、可验证、可继续迭代的工程流程。

它能做什么？
对目标视频进行 ffprobe 检测与高密度抽帧，建立完整时间轴。 
把像素位置换算为 Manim 坐标，反推标题、公式、图像和计数器布局。 
从画面颜色和数值反推代码参数，不靠模糊猜测。 
识别 Create、FadeIn、ReplacementTransform、TransformMatchingTex、数值滚动和动态图形等动画结构。 
分析转场中间帧，判断公式、标题和函数图像是否采用同步形变。 
生成可维护的 Manim 场景骨架，并通过“试渲染 → 抽帧对照 → 修正 → 高清渲染”持续逼近原片。 
对最终成片进行视觉验收，定位残留物、元素缺失、时序过快和字形问题。 
实战成果
这套技能来自《我曾九次认识世界》的真实复刻项目。它从一段约 26.6 秒的数学动画成片出发，逆向整理出约 700 行 Manim CE 0.21 源码，经历多轮渲染、抽帧比较和调整后，完成了高度接近参考视频的九张动态数学卡片作品。

为什么它强大？
普通的视频模仿往往停留在“看起来差不多”。这套技能把每一帧都视为源代码留下的证据：坐标揭示布局，颜色揭示调色板，数字揭示数学参数，转场中间态揭示动画类型，持续时间揭示代码节奏。
它采用五步闭环：
抽帧取证 → 结构反推 → 架构映射 → 渲染对照 → 视觉验收
这使 AI 不只是描述视频，而是尝试把视频背后的视觉逻辑重新实现成可编辑、可渲染、可继续创作的 Manim 代码。

使用条件
建议准备：
Python 与 Manim Community 
FFmpeg / ffprobe 
LaTeX 数学公式环境 
目标视频所需的中文字体 
能读取图片、运行命令和修改代码的 AI 工具 
不同视频的复杂度差异很大。三维特效、粒子系统、真实人物、受版权限制的素材或不可见的工程参数，可能需要用近似表达替代。技能的价值在于最大限度利用成片中可见的证据，系统地提高复刻精度和迭代效率。
