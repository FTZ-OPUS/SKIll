## 这个版本有什么特点？

- **星空背景：** 深蓝渐变、轨道、星点和淡色数学符号，贯穿整段动画。
- **九张动态卡片：** 结合公式、函数图像、面积扫描、旋转、点阵与计数器，让知识点动起来。
- **三路同步形变：** 中文标题、数学公式和图形整组同时过渡，衔接连续的数学场景。
- **可复用的制作经验：** 整理了动画节奏、场景对象管理、渲染与检查方法，方便 AI 按同一套规范继续制作。
