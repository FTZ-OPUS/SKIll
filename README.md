## 怎么交给 AI 使用？

1. 下载并解压 **SKIll.zip**，选择与你的任务相关的文档。
2. 将文档提供给 AI，让它阅读后按其中的流程完成具体任务。
3. 如果你的 AI 工具支持技能安装，可以让它把所选文档整理为该工具支持的技能格式，并安装到相应的技能目录。

可以直接这样说：

> 请阅读这份技能文档，把它整理成你支持的技能格式并安装。先检查所需环境，再按照文档中的规范完成我接下来的任务；其中的本机路径请按我的电脑实际情况调整。

也可以按任务直接使用：

- **数学动画：**“请参考《横屏大·字公式manim.md》，用大字横屏动画逐步讲解这道题。”
- **公式混剪：**“请按照《混剪skill2.0版本.md》，把这些公式做成带动态函数图的快节奏视频。”
- **视频剪辑：**“请参考《CapCut-Mate-Agent使用说明.md》，用我提供的素材制作一个可继续编辑的剪映草稿。”
- **API 接入：**“请阅读对应的 ZCode 接入教程，检查我的环境，备份配置并完成接入和验证。”
- **资料排版：**“请按照这份 LaTeX 规范，将我的 Markdown 学习资料整理成 PDF。”

## 使用前说明

- 这个压缩包收录的是 **9 份 Markdown 文档**。其中既有带技能元数据的规范，也有配置教程；具体安装方式取决于你使用的 AI 工具。
- Manim 动画需要相应的 Python、Manim、LaTeX、字体等环境；LaTeX 排版需要编译工具与相关宏包；剪辑教程需要另行安装剪映 / CapCut 和 CapCut Mate 服务。
- 文档中提到的本机一键配置脚本、插件服务及配套程序 **未包含在本压缩包内**。API 教程提供了手动配置示例；文中的个人目录和字体名称需按实际环境调整。
- 两份公式混剪文档是不同版本，均予以保留。它们使用相同的技能标识，安装时可选择 2.0 版；如需同时保留，请为两个版本设置不同的技能名称。
- API 文档保留了编写时的型号、参数和活动信息，属于当时的配置记录。模型是否可用、接口参数、免费额度与价格，请以相应平台当前说明为准。
